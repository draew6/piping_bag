# piping_bag

Unified CLI and FastAPI integration for **pgschema** (migrations) + **SQLC** (code generation).

## Install

```bash
pip install git+https://github.com/draew6/piping_bag@0.6.0.git
```

Requires `pgschema` and `sqlc` on your PATH.

## Quick Start

```bash
pb init          # scaffold db/schema.sql, db/queries/, sqlc.yaml, .env
# edit .env with your DATABASE_URL
# edit db/schema.sql with your schema
# write queries in db/queries/*.sql
pb up            # apply schema + generate Python client
```

## CLI Commands

| Command       | Description                                      |
|---------------|--------------------------------------------------|
| `pb init`     | Scaffold project files                           |
| `pb plan`     | Diff desired schema vs live database             |
| `pb apply`    | Apply migration                                  |
| `pb sync`     | Plan + apply in one step                         |
| `pb generate` | Generate Python client from SQL queries (SQLC)   |
| `pb up`       | Apply schema + generate client                   |
| `pb dump`     | Dump live DB schema to db/schema.sql             |
| `pb diff`     | Show planned changes (human-readable)            |
| `pb studio`   | Launch Prisma Studio                             |

## Project Structure

After `pb init` + `pb up`:

```
db/
  __init__.py         # auto-generated — exports QueriesDep
  schema.sql          # source of truth — edit your schema here
  queries/            # SQL queries with SQLC annotations
    example.sql
  generated/          # SQLC output (never edit)
    __init__.py
    models.py
    queries.py
sqlc.yaml             # SQLC config
.env                  # DATABASE_URL
```

## Writing Queries

Use SQLC annotations in `db/queries/*.sql`:

```sql
-- name: GetUser :one
SELECT * FROM users WHERE id = $1;

-- name: ListUsers :many
SELECT * FROM users ORDER BY created_at DESC LIMIT $1;

-- name: CreateUser :one
INSERT INTO users (email, name) VALUES ($1, $2) RETURNING *;
```

Then run `pb generate` to produce typed Python functions.

## FastAPI Integration

```python
import piping_bag
from fastapi import FastAPI
from db import QueriesDep

app = FastAPI()
piping_bag.setup(app)

@app.get("/users")
async def get_users(queries: QueriesDep):
    return await queries.list_users()
```

`piping_bag.setup(app)` manages the asyncpg connection pool automatically (composes with any existing lifespan). `QueriesDep` is a typed FastAPI dependency (auto-generated by `pb generate`) that acquires a connection per request.

## Configuration

Single env var in `.env`:

```
DATABASE_URL="postgresql://user:pass@localhost:5432/mydb"
```
